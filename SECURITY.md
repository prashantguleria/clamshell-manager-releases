# Security

If you find a security problem in Clamshell Manager, please email **hello@evenpine.com** rather than
opening a public issue. Include the Clamshell Manager version, your macOS version and steps to reproduce.

We will acknowledge your report and keep you informed. Please give us reasonable time to fix a problem
before sharing details.

Releases are code-signed and notarized by Apple, and updates are signed with Sparkle EdDSA keys. Never
download Clamshell Manager from anywhere but this repository's Releases or evenpine.com.
